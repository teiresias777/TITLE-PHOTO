Questions

Is it really free?

Yes. The cloud engine uses your own Google API key, and Google's prices and free limits apply to it. The local engine has no cost.

Does it change my original photos?

The Lightroom plugin writes to your catalog. The macOS app writes an XMP sidecar next to RAW files, which are never touched, and inside JPG files. Every batch can be undone.

Which AI model should I use?

For the local engine, a vision model such as qwen2.5vl:7b works well. Smaller computers can use the 3b version, which is faster but less accurate. Gemini gives the most consistent results.

Why is the free Gemini tier slow?

Google limits the number of free requests per minute. Title Photo paces itself to stay inside the limit. The paid plan can process several photos at once.

Does it work with the cloud-based Lightroom?

No. The plugin is for Lightroom Classic. The macOS app works with files and can be used with any catalog.
